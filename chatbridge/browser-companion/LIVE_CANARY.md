# Live browser canary

The package is not `DEPLOYED` or `PROVEN` until a signed-in Chromium browser returns evidence for all checks below.

1. The current red maximum-length banner is detected without changing its text.
2. **Start a new chat via ChatBridge** appears beside the native fallback.
3. One click produces exactly one successor tab on the same GPT/project route.
4. The restore prompt includes the capsule ID, registry title, source URL, truth rule, retained messages, omission count, and next action.
5. Auto-send either sends once or leaves the fully populated prompt for review when the send control is unavailable.
6. Reopening or refreshing cannot consume the same transfer twice.
7. No full transcript remains in durable local storage.
8. Disabling the extension restores the unmodified native ChatGPT experience.

Pass state: browser-native evidence for all eight checks. Any failure keeps the package at `TESTED_NOT_DEPLOYED` and triggers selector or route repair followed by the full regression suite.
