# Project Memory

## Governing decision

CFBE vNext optimizes the frozen owner outcome, not capability count or proof
volume. Deterministic code owns mission identity, authority, effect identity,
waiting truth, proof validity and completion language. Language models remain
proposal and diagnosis layers.

## Protected invariants

- Design is not runtime; source is not deployment; deployment is not outcome.
- A mission revision cancels stale descendants.
- Optional improvements remain exclusions or successor work.
- Automatic waiting requires a real durable wake route.
- Only current, independent, dependency-valid evidence can close criteria.
- Outcome error zero stops the mission and blocks additional work.
- Provider effects default to denied.
- Safe independent work defaults to parallel; only authority, collision,
  effect commitment and sovereign fan-in serialize.
- Alternate paths may compete, but one effect group has one durable winner.
- A bot that produced a result cannot be its verifier.
- Speed claims require paired equal-quality evidence, not simulated scheduling
  arithmetic or a single favorable run.

## Current boundary

Local deterministic Phase 2 implementation only. Multi-stream scheduling and
logical bot execution are implemented and tested; external effect execution is
deliberately absent. No remote repository admission, provider deployment,
unattended hosted worker, or operational value claim.
