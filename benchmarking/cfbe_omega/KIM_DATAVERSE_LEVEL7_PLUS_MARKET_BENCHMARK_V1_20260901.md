# Level 7+ Market Benchmark Harvest v1

This benchmark uses public official product documentation as architectural reference points, not as evidence of vendor superiority and not as permission to copy proprietary implementation details.

## Frontier patterns harvested

### Durable execution and checkpoint/resume
Market leaders increasingly separate interactive agents from durable workflow execution. Relevant patterns include step/superstep checkpoints, cross-process resume, durable worker hosting, event wakeups, long waits without active model compute, and replay-safe work.

Federation response: reuse existing durable mission runtime, result index, multistream continuity and SOL transaction identity; add persistent-carrier qualification rather than another scheduler.

### Agent/workflow separation
Leading frameworks distinguish conversational agents from explicit workflows and durable orchestration. This supports the Federation decision that chat/PRIME should be cognition/cockpit while persistent carriers own continuation.

Federation response: Mission/Maintenance/Recovery/Evolution are event classes routed into existing execution fabrics, not four new top-level autopilots.

### Governed gateway / workload identity
Modern managed agent runtimes increasingly centralize authentication, observability and policy at gateways and workload-identity boundaries.

Federation response: preserve SOVARA/SOL workload-identity and gateway gates; do not use Level 7 evolution as a pretext to weaken the existing WIF/IAM authority boundary.

### Evaluation loops
Production agent platforms increasingly integrate traces, evaluation datasets, ground truth, batch evaluation and A/B/champion-challenger validation.

Federation response: keep CFBE champion/challenger, Cognitive Policy Market, prospective owner-value cohorts and causal/value comparison as first-class promotion gates.

### Sandbox and isolated execution
Modern agent systems increasingly separate the reasoning harness from isolated execution environments and support multiple parallel workspaces.

Federation response: preserve Bubbles dynamic work cells and SOL authority fencing; do not put model-generated execution directly inside the constitutional kernel.

### Observability and independent proof
Tracing, per-step telemetry and agent/runtime observability are becoming standard production controls.

Federation response: ProofOS/Sentinel/provider-native readback remain separate from proposer cognition; successful transport never equals semantic success.

## Competitive design conclusions
1. Persistent continuation is a runtime property, not a chat feature.
2. Human-in-the-loop should be event/authority specific, not a default continuation mechanism.
3. Checkpoint/resume must avoid repeating completed consequential work.
4. Agent intelligence and durable workflow execution should remain separable.
5. Gateway/identity policy belongs outside model cognition.
6. Evaluation must compare behavior and value, not architecture descriptions.
7. Long waits should not consume active model/runtime resources unnecessarily.
8. Observability must be sufficiently structured for repair and causal analysis.
9. Multi-agent topology should be selected by mission need, not permanently instantiated.
10. Sustainable autonomy is proven through repeated operational episodes and value, not declared from source features.

## Federation differentiation target
The Level 7+ programme intentionally goes beyond a conventional agent framework by composing objective ecology, owner-attention economics, autonomy-debt accounting, architectural entropy control, constitutional evolution, capability-market pressure, lane-local recovery and proof-bound provider routing around the existing SOL/Bubbles/SOVARA/CFBE/ProofOS estate.

This remains a target architecture until empirical courts qualify its operational behavior.
