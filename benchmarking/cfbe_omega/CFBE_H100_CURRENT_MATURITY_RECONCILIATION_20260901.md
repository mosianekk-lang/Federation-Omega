## Why this reconciliation exists

PR #975 repaired an important claim-to-fruit defect by giving every gene an executable proof binding. Those bindings deliberately use only three generic proof-handler families: reuse, source composition and provider-native proof. That is safe but not granular enough to describe operational maturity.

This reconciliation therefore adds a separate maturity projection:

1. `SOURCE_REUSE_BOUND` — admitted/pre-existing capability is the implementation owner; this does not imply current provider deployment.
2. `SOURCE_COMPOSITION_BOUND` — deterministic source/control composition exists; this does not imply provider runtime.
3. `PROVIDER_VERIFIED` — the exact provider gate defined by the H100 gene was independently proved.

No generic proof handler may promote a gene above the evidence actually associated with it.
