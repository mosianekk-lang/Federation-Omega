## Architecture rule learned from this chat

**One capability, one canonical host, one proof path.**

When multiple PRs implement the same semantic capability, CFBE must select a champion by:

1. exact-head proof state;
2. canonical-host fit;
3. reuse of existing state/authority/proof planes;
4. lower owner burden and code surface;
5. matched performance evidence;
6. reversibility and migration cost.

Losing candidates remain gene donors until their unique value is migrated or rejected. They must not become permanent parallel control planes by default.
