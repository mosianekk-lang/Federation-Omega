# Level 7+ done criteria

Source implementation is done only when its exact head passes all blocking repository courts and is merged on fresh ancestry.

Operational Level 7 is done only when all of the following are observed and proof-bound:
- persistent continuation without chat-turn dependency;
- at least the configured maintenance and recovery cohorts;
- avoidable owner interruption rate at or below the configured threshold;
- no provider-local failure causing global stall in the qualifying cohort;
- prospective owner-value minimum satisfied with no protected quality/reliability regression;
- rollback and regression evidence current;
- provider-native readback for every provider-specific operational claim;
- newest serving-main Phoenix green.

Level 8+ remains a separate frontier qualification and cannot inherit Level 7 proof.
