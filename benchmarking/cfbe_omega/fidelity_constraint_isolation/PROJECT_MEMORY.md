# Project Memory

## Canonical decision

The CFBE-Ω Fidelity and Constraint Isolation layer extends existing controls. It does not replace the protected anti-dilution baseline, the generic `CapabilityResolutionGate`, RealityGuard, or the provider-specific constraint resolver.

## Governing invariants

- Canonical intent and source are immutable inputs.
- A platform constraint is execution metadata, not permission to weaken source.
- Equivalent adapters are eligible only with preservation, deterministic test, rollback, authority, cost, burden, and external-effect evidence.
- An unresolved capability remains visible as an AO-CRA build trigger.
- `CAN`, `DONE`, provider-ready, deployed, and proven states remain evidence-distinct.
- Source verification is not runtime deployment.

## Current maturity

The package begins at `SOURCE_IMPLEMENTED`. Promote it only with the evidence required by the contract ladder. Record provider-main admission separately from runtime deployment.

## Rollback

Remove the additive package and exports or discard its generated result. No canonical source, database, queue, secret, provider, or deployment state is mutated by evaluation.
