# CFBE Hyperleverage Wave 2 — Scientific Capability Compiler Benchmark
Date: 2026-09-01

## Decision

Wave 2 should not create another sovereign orchestration layer. The highest-value evolution is to turn CFBE from a frontier benchmark/harvest engine into a **scientific capability compiler**:

**DISCOVER -> DECOMPOSE -> COMPARE -> FALSIFY -> CLEAN-ROOM REIMPLEMENT -> MEASURE CAUSAL VALUE -> ADMIT MINIMUM CAPABILITY -> OBSERVE ECOLOGY**

This programme routes all 100 Wave 2 genes through a source/control contract while adding deep executable controls for the 22 highest-leverage genes. Provider effects and stable promotion remain disabled.

## Existing Federation advantage

The current estate already contains strong reusable primitives for:
- mission/autonomy and metacognitive state;
- proof class separation and no-self-promotion;
- owner-value and observable-burden courts;
- durable checkpoint/idempotency and recovery semantics;
- source provenance, SLSA/artifact attestations and current-head admission;
- capability-gap/reuse-first governance;
- trace, failure-learning, contradiction and rollback controls.

Wave 2 therefore specializes only the missing scientific-harvest, portability, memory-influence, taint, protocol, API-compilation and ecology layers.

## Anti-bloat law

A harvested capability is not admitted merely because a leader has it.

Every gene must pass:
1. measured gap;
2. public provenance;
3. license/standard admissibility;
4. measurable owner-value hypothesis;
5. reuse/extension/composition check;
6. exact authority if effects are involved;
7. independent proof;
8. no-regression / owner-value promotion gate.

## Stronger scientific doctrine

Wave 1 asks:
> What frontier capability exists and how can the Federation obtain equivalent or better control?

Wave 2 asks:
> Which primitive actually causes the advantage, is it absent here, can the causal benefit be falsified, and what is the smallest independently admissible implementation that captures it?

This is the intended CFBE evolution.

## Truth boundary

This source tranche does **not** prove:
- market superiority;
- provider deployment/runtime;
- physical-device control;
- continuous online evaluation in production;
- owner-value improvement;
- stable capability promotion.

Those remain empirical/provider gates.
