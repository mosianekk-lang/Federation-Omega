# Formation Specification

- Mission: certify four symmetric read-only adapter profiles with zero canonical dilution.
- Authority: A1 for discovery, local execution, tests, and scorecard generation. A2 is separately required for a GitHub purpose branch or pull request. Merge is excluded.
- Cost and burden: zero recurring cost and zero owner tasks.
- Effects: Gmail, Drive, and Canva writes are forbidden. The certification runtime performs no GitHub write.
- Reuse: `fidelity_constraint_isolation` remains the fidelity and constraint authority; `bubbles_work_graph_adapter_v1` remains the scheduler adapter.
- Stop: all four courts pass, live read canaries are truthfully classified, the scorecard receipt verifies independently, and exact source lineage is preserved.
- Rollback: discard generated artifacts and revert the purpose-branch commit. No provider rollback is needed because the court has no provider effects.
