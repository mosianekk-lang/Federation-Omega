## Hyperleverage 100 implementation model
The genome contains exactly 100 non-duplicate improvements:
- `REUSE_VERIFIED`: existing admitted capability is the implementation.
- `COMPOSED_BY_FABRIC`: this package adds bounded source-level policy/compiler controls that activate the capability using existing owners instead of another subsystem.
- `PROVIDER_GATED_CONTRACT`: source/control contract is created now, but provider runtime remains explicitly unproven until authority and provider readback exist.

The compiler never self-promotes stable state and never grants provider/effect authority.
