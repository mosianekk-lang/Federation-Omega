# SOVARA Ω — Epistemic Decision & Prediction Fabric v1

Status: SOURCE_CANDIDATE / A1_INTERNAL / NO_PROVIDER_EFFECT_AUTHORITY  
Architecture: Living State + Cognitive Policy Market + causal/counterfactual engines + calibration + metacognition → EDPF → SOL/SOVARA admission  

## Purpose

EDPF makes material Federation cognition accountable to later reality. It does not add another world model, scheduler, memory root, proof plane, sovereign orchestrator or provider executor. It composes existing evidence, beliefs, predictions, challenger calibration and post-outcome readback into deterministic receipts.

## Core law

Every material decision should expose, where applicable:

1. the claims it depends on;
2. evidence provenance and independence;
3. current probability/uncertainty;
4. competing decision options;
5. expected outcome, value, latency, owner burden and risk;
6. whether an independent challenger is required;
7. the highest-value next evidence when uncertainty can still change the decision;
8. a deterministic advisory decision receipt;
9. later observed outcome and proof refs;
10. predictor calibration update.

A proposal, prediction or model consensus never creates canonical truth or provider authority.

## Intelligence improvements

### One epistemic state
Claims carry explicit type, probability, evidence refs, causal/contradiction links and expiry metadata. Same-source repetition does not count as independent corroboration.

### Prediction accounting
A predictor states a probability before outcome. When independently read-back reality resolves the event, EDPF updates empirical accuracy, Brier score and absolute calibration error.

### Dynamic thinker allocation
Predictor allocation combines historical trust weight, task relevance, independence, expected information gain, cost and latency. New/unmeasured predictors receive a neutral prior rather than an invented superiority score.

### Active evidence acquisition
Evidence candidates are ranked by decision-flip probability, uncertainty reduction and freshness gain minus acquisition cost/risk. The system prefers evidence that can change action, not evidence merely because it is available.

### Decision-sensitive uncertainty
High uncertainty or external-effect proposals require independent challenger provenance. High but resolvable uncertainty emits SEEK_EVIDENCE instead of pretending confidence.

## Authority and truth boundary

Always false in EDPF:

- dispatch_authorized
- external_effect_authorized
- stable_self_promotion_allowed

Provider-native readback, exact action authority, credentials/IAM, paid inference, deployment, traffic, publication, communication and destructive effects remain outside this module and continue through their existing SOVARA/SOL gates.
