## Persistent smart workaround law

Every blocked analysis route must move through:

REUSE_EXISTING_ANALYSER
→ REBIND_CURRENT_TOOL
→ REPAIR_PARSER_OR_ADAPTER
→ EXTEND_FORMAT_OR_PROTOCOL_DECODER
→ COMPOSE_INDEPENDENT_EVIDENCE
→ HARVEST_PUBLIC_DOCUMENTED_MECHANISM
→ BUILD_MINIMUM_RESIDUAL_ANALYSER
→ HOLD_IF_RIGHTS_OR_AUTHORITY_REMAINS

Same-semantic failure cannot be retried unchanged.

Examples:
- Python unavailable → PowerShell/Node/native parser rather than manual owner work.
- proprietary binary format → metadata/strings/imports/sample-differential/public docs,
  not access-control circumvention.
- closed-source software → black-box behavioural specification and public mechanism
  harvest, not a claim of proprietary source reconstruction.
- router API unavailable → DHCP/ARP/DNS/log/provider readback or passive reappearance,
  not authentication bypass.
- protocol undocumented → authorised/passive message-shape/state-machine inference,
  with every unknown retained.
- stale IP/MAC evidence → temporal identity graph and DHCP epoch separation.
- inaccessible provider surface → alternate authorised receiver or evidence source;
  CONNECTOR_STATE never becomes CAPABILITY_STATE.
