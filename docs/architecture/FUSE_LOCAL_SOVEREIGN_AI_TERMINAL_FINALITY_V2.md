# FUSE Local Sovereign AI — Autonomous Formation & Terminal Finality v2

Status: source candidate on the existing FUSE Autonomic Completion / Sovereign Plane lineage. This is not a new sovereign controller.

## Objective

Converge FUSE LocalLLM and the wider FUSE estate into a locally owned Windows AI workstation that can serve as the owner's primary ChatGPT alternative, is distributed through the owner's Google Drive, can be installed on another Windows PC, and cannot claim completion until every mandatory terminal predicate has evidence-backed maturity.

## Why terminal debt

Packet completion and source admission are not product completion. A product issue becomes durable debt until its relevant maturity vector is proven.

Each debt item includes:

- predicate identity;
- family;
- dependencies;
- collision keys;
- required maturity stages;
- passed maturity stages;
- owner-only flag;
- effect class;
- priority;
- terminal unlock value;
- estimated cost;
- evidence refs;
- blockers;
- failure fingerprint;
- attempts.

## Zero-debt law

`OPEN_MANDATORY_TERMINAL_DEBT == 0` is a non-compensating finality floor.

It is not sufficient that:

- every current WorkPacket is done;
- CI is green;
- source is merged;
- an installer exists;
- one PC works;
- an artifact was uploaded to Drive;
- OpenAI can be used as a fallback;
- a model responds to chat.

The Local Sovereign AI profile separately requires Windows product, local model fabric, chat/reasoning/memory/tools, agents, automations, productivity, code, creative, browser/device/data, diagnostics/repair, installer/provisioning, OpenAI-disabled operation, offline core, recovery, updates/LKG, provenance/licensing/security, Drive release, cross-PC install, cross-hardware compatibility, natural owner workload and commercial product/release courts.

## Autonomous debt burner

The burner may run only debt whose dependencies are closed, blockers are empty and required authority is available. It ranks debt by terminal unlock, priority and estimated cost, and compiles collision-safe waves.

A blocked debt does not global-stall disjoint READY debt.

No handler means a typed blocker, not a false pass.

## Maturity

Default maturity vector:

`DESIGN -> SOURCE -> BUILD -> TEST -> INTEGRATION -> RUNTIME -> SEMANTIC -> RECOVERY -> SECURITY -> UX -> OWNER_VALUE`

Each product predicate may declare only the dimensions that apply.

Maturity is evidence-driven; packet completion cannot silently mark maturity.

## Cross-chat durability

Terminal debt is persisted through the existing RunStore SQLite/WAL state. New chats/clients rejoin the mission; they do not recreate the debt from memory.

## ChatGPT independence

ChatGPT/OpenAI is optional acceleration. The product cannot reach finality without the `OPENAI_DISABLED_VERIFIED` and `OFFLINE_CORE_VERIFIED` predicates.

## Distribution finality

A Google Drive upload is not distribution finality. The profile requires provider readback, package/hash/provenance checks and a clean second-PC install.

## Commercial truth boundary

This mechanism makes gaps durable and machine-actionable. It does not by itself prove Windows runtime, model availability, cross-PC installation, trusted code signing, buyer demand, revenue, Microsoft/Google product parity or commercial readiness. Those remain terminal debts until separately proven.
