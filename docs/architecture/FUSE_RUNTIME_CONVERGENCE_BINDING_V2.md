# FUSE Runtime Convergence Binding v2 — FRCB-002

Status: SOURCE CANDIDATE / STACKED ON FRCB-001 / A1_INTERNAL / NO EXTERNAL EFFECTS

## Mission

FRCB v2 advances exactly one maturity boundary: OH50 is no longer accepted only as a
well-formed caller-supplied SwarmManifest. The manifest must be generated by the
existing HORIZON-Ω and Formation swarm primitives and accompanied by a deterministic
producer-invocation receipt that binds the exact manifest consumed by OF50.

This is a composition layer, not another autonomous controller.

## Reused mechanisms

V2 reuses:

- ao_harmonic_v3.horizon.HorizonOmega for adaptive foresight;
- formation_omega.autonomic_fabric.MissionSwarmPlanner for authority-isolated specialist formation;
- federation.of50_ace_v1.SwarmManifest and the canonical H01..H50 contract;
- FRCB v1 for AAREK invocation/completion-state binding and OF50 execution.

No new scheduler, proof plane, memory root, foundry, provider runtime or top-level
completion authority is created.

## Producer route

The OH50 producer adapter:

1. invokes HORIZON-Ω with a requested depth of 50;
2. requires at least 50 returned horizon nodes;
3. invokes the existing Formation mission-swarm planner;
4. maps the first 50 horizon nodes onto OF50 H01..H50;
5. binds each cell to deterministic evidence material;
6. emits an exact SwarmManifest;
7. emits a deterministic receipt binding:
   - mission;
   - objective;
   - A1 authority ceiling;
   - producer identity;
   - 50-horizon count;
   - manifest digest;
   - HORIZON-Ω run digest;
   - specialist-swarm digest;
   - explicit truth boundary.

## What v2 proves

V2 proves that the existing in-process HORIZON-Ω and MissionSwarmPlanner producer
primitives were invoked to construct the OH50 manifest and that the exact manifest
digest is the one consumed by FRCB/OF50.

It does not prove an independent signature or remote producer attestation. It does
not prove that a prediction is a fact. It does not prove Formation Foundry execution,
Alpha-Omega runtime execution, provider execution, provider semantic readback, F130
terminal commit, native ChatGPT serving-stack interception or whole-mission
COMPLETE_VERIFIED.
