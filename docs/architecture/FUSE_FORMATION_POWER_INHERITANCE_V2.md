# FUSE Formation Power Inheritance v2

Status: additive successor to FUSE Formation Surface Load Balancer v1. It composes existing Formation, CFBE Agentic Frontier, Autonomic Mission Fabric, AO-HARMONIC Resource Market, OmniSurface routing, FDOF/SICF and ProofOS/Reality Judge. It creates no new sovereign controller, scheduler, mission bus, authority root, truth root, memory root, proof root or provider runtime.

## Objective

Every FUSE workflow inherits formation intelligence before route execution. "Every" means every workflow entering the governed FUSE mission/workflow fabric: research, engineering, evidence, creative, automation, cloud/runtime, Windows/device, communications, release, long-running and general workflows. A trivial workflow may compile to a one-surface FAST formation; global inheritance does not force wasteful provider fan-out.

## Global execution laws

1. Formation compile occurs before governed route execution.
2. Minimum sufficient proven portfolio; never "call everything".
3. Maximum one mutating lane; parallelism is for disjoint READY work.
4. Critical path receives first capacity; side lanes may proceed when collision-safe.
5. Independent cognition requires distinct provider and correlation domains.
6. Surface/provider failure remains local unless a shared dependency is proven.
7. Epoch, currentness, proof lease, health, quota/cost, evidence, Judge rejection or route failure can trigger selective replan.
8. Second same-semantic failure requires a changed mechanism.
9. Unknown possible effect requires readback before retry.
10. Learning may change route preference and exploration budget, never authority.

## Capability inheritance vs runtime truth

A compiled capability gene means the workflow requires/uses that mechanism contract. It does not prove the underlying provider, model, device, tool or effect path is currently callable. Provider and surface execution remain gated by current capability/readback state from the Formation Surface Load Balancer and existing provider/surface registries.
