# N-OMEGA + CFBE-Ω Agentic Frontier Superstack v1

## Architecture

N-OMEGA and CFBE-Ω are integrated but remain asymmetrical:

- **N-OMEGA** is the mission compiler and execution manager.
- **CFBE-Ω** is the independent benchmark, challenger, capability-harvest and evolution governor.

The lifecycle is:

`CFBE_PREPASS -> N_COMPILE -> EXECUTE -> PROVIDER_OR_NATIVE_READBACK -> INDEPENDENT_ASSURANCE -> OWNER_VALUE_SCORE -> CFBE_POSTPASS -> PERSIST_TERMINAL_RECEIPT`

This prevents N-OMEGA from becoming its own benchmark authority while still making CFBE a native part of every substantial N mission.

## Frontier synthesis

The compiler encodes 40 proof-bound capability genes across 18 domains from a 17-surface reference set spanning foundation-model agent stacks, enterprise agent platforms, agent-development frameworks, workflow/RPA systems and CX/bot platforms. It copies no proprietary vendor source. Architectural patterns are mapped into existing Federation capabilities wherever possible.

Modes: 15 `REUSE_VERIFIED`, 20 `COMPOSED_BY_FABRIC`, 5 `PROVIDER_GATED`, 0 unrouted.

## Hard invariants

- one mutating lane maximum;
- external models remain `PROPOSAL_ONLY`;
- no stable self-promotion;
- provider-gated routes require native provider identity and semantic readback;
- consequential work adds action-specific authority, idempotency and post-effect readback;
- stable promotion requires independent assurance and positive owner-value evidence;
- source/CI proof never implies provider effect, behavioral maturity, owner value or market superiority.
