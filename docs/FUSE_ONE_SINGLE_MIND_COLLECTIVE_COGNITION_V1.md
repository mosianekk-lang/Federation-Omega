# FUSE One Single-Mind Collective Cognition v1

Status: bounded source implementation for Gate 0. This component is not a controller, truth root, proof root, scheduler, queue, identity root, memory root, or learning plane.

## Purpose

Provide deterministic provider-neutral primitives for the existing FUSE One / Mission Bus / FDOF fabric:

- `SemanticObjective` normalization and exact fingerprinting.
- `SpawnRecord` / execution-actor coordination contract.
- Pairwise sibling conflict classification.
- Semantic duplicate routing (`JOIN_EXISTING`, `CONSUME_RESULT`, etc.).
- Derived Active Cognition Map projection.
- Mandatory sibling preflight output.
- `ContinuationCapsule` digest for resumable handoff.
- Typed contradictory belief preservation.
- Learning projection that explicitly does not inherit authority/provider permissions.

## Truth boundary

Source and deterministic tests prove only source-level coordination semantics. They do not prove hidden chat-to-chat awareness, provider runtime, natural multi-spawn behavior, recovery, value, or `SINGLE_MIND_MULTI_MISSION_HARMONY_BEHAVIOUR_VERIFIED`.

Cross-spawn awareness exists only when actors externalize relevant deltas into provider-visible shared state and siblings fresh-read them.

## Conflict law

`DISJOINT_READ` and `DISJOINT_WRITE` may proceed concurrently when broader authority permits.

`OVERLAPPING_WRITE`, `SHARED_EFFECT`, `CANONICAL_STATE`, and `UNKNOWN` require serialization/hold through current FDOF/authority/reconciliation.

Expiry never equals release.

## Epistemic law

Coordination visibility is separate from conclusion visibility. `BLIND_CHALLENGER` and `JUDGE_ISOLATED` preserve independence. Contradictory evidence is retained rather than overwritten. Majority vote is not truth.

## Learning law

Reusable learning may propagate to compatible receivers. Authority, provider permissions, private-data access, effect rights, production maturity, legal authority, and financial authority never propagate from sibling work.
