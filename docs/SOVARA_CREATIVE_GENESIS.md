# SOVARA Creative — Genesis Source Contract

SOVARA Creative is the sovereign multi-format creative-production specialization of SOVARA Ω.

## Genesis scope

This first source layer implements only:

- creative mission-genome validation;
- content and privacy classification;
- mature/adult-oriented hard eligibility gates for real-person work;
- route-policy evaluation;
- sovereign-first routing;
- external-provider policy recheck state;
- digital no-paper fallback;
- regression tests for the above.

It does **not** yet implement media generation, OpenRouter calls, self-hosted model serving, Google Cloud deployment, publishing effects, or value measurement.

## Architectural rule

External AI models have proposal authority only. Provider/model quality never grants state, tool, publishing, consent, rights or proof authority.

## Creative classes

The system supports general brand/commercial, social, editorial, fashion/glamour, image, video/film, audio/music, virtual-creator and presentation/visual-storytelling workflows, plus a separately governed mature/adult-oriented production class.

The mature/adult-oriented class is fail-closed for ambiguous-age/minor, coercive/non-consensual, hidden-camera exploitation or non-consensual sexualized real-person impersonation scenarios. Real-person mature missions require externally established adult/consent/rights provenance; model output never establishes those facts.

## Continuity rule

A model/provider refusal or incompatibility is a routing event, not a prompt-obfuscation problem:

1. eligible sovereign/self-hosted route;
2. eligible pre-verified external route;
3. eligible creative-tool adapter;
4. non-generative digital editing/production fallback.

Paper/manual offline workflow is not a technical fallback target.
