# SOVARA public-safe source projection

This directory contains only public-safe SOVARA architecture and immutable release-identity metadata.

- `SOVARA_CONSTITUTIONAL_RUNTIME_PUBLIC_PROJECTION.md` — public architecture projection.
- `SOVARA_RELEASE_IDENTITY_REGISTRY_V2.json` — immutable release-role/hash registry.
- `SOVARA_PUBLIC_PROJECTION_TRUTH_BOUNDARY.md` — privacy, authority and proof boundary.

Private evidence, secrets, credentials, private recovery artifacts and provider-private identifiers must remain outside this public repository.
