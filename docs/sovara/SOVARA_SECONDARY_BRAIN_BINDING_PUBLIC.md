# SOVARA ↔ Secondary Brain public binding

Secondary Brain is a read-only canonical resolver/context assembler. For a mission it should return one current system/release/source/state/route or an explicit conflict object with open gates and confidence.

It must not:
- mint provider authority;
- silently promote historical proof to current proof;
- resolve SOVARA by semantic version alone;
- turn model output into canonical truth;
- become a second sovereign authority root.

SOVARA remains the mission/authority/proof control plane. Fresh provider readback outranks stale registry projections.
