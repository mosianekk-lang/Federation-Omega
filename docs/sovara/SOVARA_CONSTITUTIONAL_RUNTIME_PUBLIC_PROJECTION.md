## Constitutional architecture

SOVARA is an owner-rooted mission, authority, routing, continuity and proof control plane. It does not replace the Federation ecosystem. The intended hierarchy is:

1. Human owner/final authority.
2. SOVARA mission, authority and proof control plane.
3. Preserved durable runtime substrates and specialist Federation systems.
4. Replaceable provider/application adapters.
5. Independent proof and semantic readback.
6. Structured canonical state with human-readable projections.

The runtime composition includes:

- structured canonical mission/event/evidence/artifact/decision/capability state;
- machine-readable Federation System Contracts;
- least-privilege execution cells;
- mission/action/provider/target/scope-bound credential leases;
- digital-twin simulation for consequential actions;
- independently veto-capable proof states;
- multi-provider intelligence proposals with disagreement preservation;
- interface independence;
- scientific learning promotion with red-team and regression gates.
