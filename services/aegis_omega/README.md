# AEGIS-Ω

AEGIS-Ω is a **defensive-only**, evidence-first mobile threat-defense control plane. It combines privacy-minimised event intake, provenance sealing, deterministic + anomaly-assisted evidence fusion, case management, governed response policy, and an offline evolution-certification gate.

It is intentionally **not** an exploit framework, spyware platform, credential collector, covert surveillance agent, persistence toolkit, or command-and-control system.

## Production topology

The included GCP blueprint targets:

- Cloud Run — stateless AEGIS API/control plane
- Pub/Sub — authorized telemetry/event bus
- BigQuery — analytical event lake
- Cloud Storage — evidence objects with retention/versioning
- Firestore — case/control state
- KMS — signing/encryption roots
- Secret Manager — integration secrets
- Artifact Registry + Cloud Build — supply-chain/build path
- Cloud Logging/Monitoring — operational telemetry

Google AI Studio/Gemini is an **explanation/orchestration adapter only**. It is not allowed to make a final compromise determination or autonomously execute a high-impact response.

```bash
pip install -e '.[dev]'

```

```bash
pytest

```

## Proof model

`production_status.json` is generated by `scripts/verify_release.py`. A release is not called provider-production unless provider-native deployment and readback evidence exists.

The 10× target is a **benchmark objective**, not a claim. See `docs/10X_BENCHMARK.md`.
