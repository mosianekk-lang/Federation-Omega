# Security and Responsible Use

AEGIS-Ω is for authorized defensive security, consensual forensics, hardening, monitoring and incident response.

Never use it to gain unauthorized access, surveil people covertly, collect credentials, persist on third-party devices, bypass platform protections, exfiltrate private data, or reproduce mercenary-spyware capabilities.

Report vulnerabilities privately to the system owner. Do not place secrets in issues, logs, code, Apps Script source, Terraform state, or benchmark datasets.
