# Federation Omega GCP Admin MCP v0.2.2

This is the additive Alpha-Omega safety-hardened successor to the immutable v0.2.1 package. It preserves the complete 17-tool surface and adds independent proof gates; it does not replace or dilute any baseline tool.

## What is stronger

- Bounded multi-stream discovery, integrity, authority and assurance lanes converge into exactly one serialized effectful release lane.
- WIF preflight requires the exact numeric GitHub repository and owner identities, active provider mappings, restrictive conditions and least-privilege IAM readback.
- Release actions are pinned to immutable commits and the deployment workflow is manual dispatch only with non-cancelling concurrency.
- Cloud Build requires a full 64-hex image digest, a fenced release, a zero-traffic tagged canary, rejection of unauthenticated access, private IAM, exact version health and two-pass provider lineage.
- Failure recovery distinguishes `NOT_FOUND` from authorization/transient errors, compares the restored traffic map exactly, and proves first-service deletion by absence readback.
- `apps_script_rollback` retains legacy caller compatibility while reporting compatibility mode and preserving post-write source verification.
- Optional audit persistence failures cannot overwrite the already-observed provider operation result.

## Proof boundary

Local source, tests, tool preservation, workflow syntax and release controls are proven. Live WIF, Cloud Build, Cloud Run, IAM and provider permanence are not yet proven. The operating level is `ON_DEMAND_GOVERNED`; `durableAutonomyProven` is false.

The release workflow remains dormant until its provider-native authority job passes. No service-account key JSON is accepted.
