# Capital Intelligence OS — Architecture v0.8

`DOCUMENT/EVIDENCE → HASH/VERSION/CLASSIFICATION → AUTHORIZED VAULT/SEARCH → DILIGENCE/QoE → VALUATION/MARKET STRESS → WORKSPACE SNAPSHOT → GUIDED OWNER or PROFESSIONAL VIEW → DECISION/AUTHORITY → OUTCOME LEARNING`

The user modes share one evidence/decision substrate. The vault fails closed on UNKNOWN classification and enforces role-based access for confidential, clean-team, privileged and restricted content.

Production binary storage/parsing remains outside this reference layer until provider security and retention controls are proven.

The provider runtime is intentionally narrower than the local product surface:

`CLOUD RUN IAM → X-CIOS-TOKEN → FIXED TENANT/USER → POOLED POSTGRES STATE → SEPARATE APPEND-ONLY AUDIT`

The production control sequence is:

`EXACT MAIN → DIGEST IMAGE → MANAGED RECOVERY READBACK → ZERO TRAFFIC → SEMANTIC/REPLAY CANARY → BASELINE ROLLBACK → RECOVERY CANARY → RECEIPT-GATED PROMOTION`

Document routes remain absent from this provider sequence until malware/DLP and resource-isolated parsing are independently qualified.
