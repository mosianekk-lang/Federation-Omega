# Formation Specification — CIOS Genesis v0.1

## Objective lock
Build the smallest complete executable nucleus that proves EvidenceOps can combine M&A, capital allocation and public-market intelligence without leaking private deal information into trading or inheriting financial authority.

## Competing routes considered
1. **Greenfield monolith** — rejected: duplicates proven Federation components and increases control-plane sprawl.
2. **Thin documentation-only overlay** — rejected: fails the build/execute/verify directive.
3. **Composable domain kernel over existing Federation primitives** — selected: strongest reuse, lowest authority expansion, easiest deterministic testing.
4. **Immediate cloud microservices deployment** — deferred: runtime/provider authority and production readback are separate gates; source existence cannot prove deployment.

## Selected architecture
A provider-neutral Python domain kernel with deterministic algorithms, explicit information classification, proof graph, M&A lifecycle, capital-ranking engine, bounded Autopilot and maturity governor. Existing Algorithm Foundry and Provenance Passport remain reusable upstream/downstream primitives.

## Innovation frontier
- Reuse: Provenance Passport + Algorithm Foundry + existing authority doctrine.
- Incremental: deterministic proof graph + authority firewall + Autopilot event loop.
- Materially different: Decision Reversal Threshold and Fragility Cascade as machine-readable capital-risk primitives.
- Highest-information reversible experiment: synthetic public-rate shock propagated through valuation dependencies while an attempted live-market action remains denied.
