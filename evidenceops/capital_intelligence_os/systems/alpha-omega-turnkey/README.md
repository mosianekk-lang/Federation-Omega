# Alpha→Omega Turnkey Build Engine

A Formation Innovation Engine derivative that converts a concept into a governed, decomposed, buildable, deployable and maintainable system plan.

## Operational contract

The engine targets working systems, not prototype accumulation.

`INTAKE → DISCOVERY → DECOMPOSITION → ARCHITECTURE → BUILD → TEST → DEPLOY → VERIFY → OPERATE → MAINTAIN`

A provider deployment is promoted only after:
- provider deployment receipt;
- execution log;
- exact target readback;
- health check;
- persistence check;
- rollback test.

## Quick start

```bash
python -m pip install -e .
alpha-omega examples/concept.json --workspace ./workspace --build
```

The included build path creates a working local operational package. Provider deployments remain provider-authority gated.
