# Governed learning loop

SIG improves only through source-controlled Formation cycles. It does not rewrite itself, alter a foundation model, expand authority, create credentials, contact people, incur cost or promote its own changes.

Every discovered defect or contradiction follows this lifecycle:

`OBSERVED → FINGERPRINTED → REPRODUCED → PATCHED → REGRESSION_TESTED → INDEPENDENTLY_REVIEWED → FORMATION_PERMITTED → PUBLISHED_DRAFT → FORWARD_TESTED`

Promotion is prohibited when any state is skipped. A repeated incident is deduplicated by its fingerprint and patches the smallest existing control before a new competency is considered.

## Required learning record

Each incident records:

- exact claim and observed fruit;
- severity, recurrence, affected surface and control;
- user correction and measurable failure condition;
- smallest safe code or policy repair;
- original failure-first test and healthy-case test;
- rollback boundary and authority/cost effect;
- independent review result and Formation permit reference;
- EvidenceOps/Local Bible transaction reference when separately authorised;
- later forward-test result before `BEHAVIOR_PROVEN` may be claimed.

## Participating elements

- Contracts learn by narrowing accepted schemas and replacing free text with closed enums, hashes and references.
- Policy learns by converting reproduced bypasses into deterministic default-deny rules.
- Store and worker learn through transaction, fencing, stop, completion and secret-handling regression tests.
- Static verifier learns new forbidden architecture patterns and required controls.
- Tests preserve every reproduced failure and a healthy counterpart.
- Documentation and handoff files record current limits, changed decisions and rollback conditions.
- Formation fleet reviewers receive the new source hash and must independently reproduce closure.
- EvidenceOps receives only validated, generic, reusable lessons through its governed continuity transaction; private evidence and raw secrets are excluded.

The umbrella adaptive decision is `PATCH_EXISTING`, with no authority expansion, no recurring cost and no self-promotion. Individual incidents and independently derivable fingerprints are recorded in `LEARNING_INCIDENTS.json`; every current entry remains `REMEDIATED_PENDING_FROZEN_SOURCE_RECHECK` and `behaviorProven` remains false.
