# Governed learning loop

Learning is evidence-driven and additive:

`claim -> observed fruit -> fault -> minimum rule -> regression -> independent readback -> candidate promotion`

An incident does not automatically become doctrine. A rule is eligible only when it is reusable, does not widen authority, carries zero recurring cost, preserves privacy and stop semantics, has a failure-first regression, and passes a separate Formation competency gate.

## Initial durable lessons

1. Source existence is not attachment. Keep every live coverage flag false without provider-authoritative reconciliation.
2. Heartbeats are recommendations. A capability score never becomes effect permission.
3. Whole-system awareness cannot be inferred from sampled chats. Require exact inventory and registered current emitters.
4. Cross-surface payloads should carry codes and hashes, not source bodies.
5. Stop must change generation so stale work fails cryptographically and semantically.
6. One on-input pull aggregator prevents competing schedulers and retry storms.
7. Semantic readback must compare the claimed latest state, not only caller-supplied hashes.
8. Child/spawn inheritance must preserve owner, matter, privacy, authority, cost, and control-generation ceilings.
9. A signed child envelope does not prove its parent. Forwarded acceptance requires the complete signed root-to-current lineage and immutable semantic comparison at every hop.
10. A valid destination signature does not establish receipt attribution by itself. Receipt identity, semantic hash, scope, accepted envelope, control generation and acceptance time must all be independently cross-bound.
11. Respawn hashes do not replace semantic policy-root comparison. Owner, matter, classification, authority, schema, adapter, signing version and both generations must agree.
12. Hashing arbitrary observation values does not make them metadata-safe. Dispatch the exact adapter-source schema before hashing and reject unknown sources, fields and prose.
13. Version labels are executable security contracts. Support only implemented signing versions and require exact parent-child inheritance.
14. A test-count claim is not reproducible proof. Publish and execute the exact dependency-free module command in the build contract and CI.
15. A generic uppercase code regex is not privacy enforcement. Bind every code leaf to a field-specific namespace or closed vocabulary, reject credential-shaped substrings first, and document that syntax cannot prove intent or semantic absence.
16. Lexical path containment is not filesystem containment. Resolve every Git-reference component beneath the real `.git` root and reject dot, parent, empty, malformed and symlink segments.
17. A correctly signed receipt can still rely on stale authority. Verify the destination registration is fresh at explicit `now` and that acceptance occurred inside its registration window.
18. A respawn root can be valid while one registry record is stale. Require freshness for every record used by semantic readback.
19. A caller-supplied policy hash is a claim, not proof. Recompute one canonical hash from all policy-defining fields and compare it during construction.
20. A valid hash chain does not prevent control-generation rollback. Enforce nondecreasing generations during append, verification and readback.
21. Standard JSON decoding silently accepts duplicate keys. Use one strict decoder with duplicate-key rejection at every governed JSON boundary.
22. Frozen dataclasses do not freeze caller-owned lists. Snapshot list or tuple inputs into immutable tuples before any contract stores them.
23. Preserving a facade does not preserve its authority. Existing engines, databases, schedulers and MCP surfaces must delegate to one verified authority or remain inventory-only.
24. Catalogue availability is not ingress authority. `EXECUTABLE_NOW`, session availability, source presence and unhosted implementation states can support inventory but never acceptance.
25. Privacy projection is weaker than data minimization. Do not accept raw task or chat content at a lower tier and hash it later; prohibit it at the ingress contract.
26. Operation-ID replay safety requires comparison of the complete canonical payload. Returning the first receipt for a changed payload is an idempotency failure.
27. Scheduler reconciliation can silently become a second recommendation engine. Scheduled heartbeat code must expose zero decisions and perform no route ranking, retry advancement or dispatch.
28. A runtime manifest or README route list is not API implementation. Verify endpoint code, authentication tests and hosted semantic readback before claiming an API or MCP capability.
29. A hash-only Bible heartbeat is not trust continuity. Require registry-bound signing, complete lineage, fresh destination receipt and stop-generation verification.
30. Replacing unsafe tests without a one-to-one coverage map can dilute controls. Map every legacy regression to a preserved or explicitly strengthened behavior and keep the corrected count nondecreasing.

## Promotion states

`OBSERVED -> REPRODUCED -> REGRESSION_ADDED -> INDEPENDENTLY_VERIFIED -> FORMATION_AUTHORIZED -> PUBLISHED_CANDIDATE -> BEHAVIORALLY_PROVEN`

This package reaches only the states supported by the current proof; it never self-promotes.
