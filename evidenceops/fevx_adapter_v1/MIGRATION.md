# Migration from declarative FEVX-MCOE to executable adapter

`evidenceops/fevx_mcoe` remains the controlling EvidenceOps orchestration doctrine. This adapter does not replace it. It enforces the missing executable boundary:

1. typed case packet;
2. recursive case-wall validation;
3. immutable source and verified-fact hashes;
4. actual twenty-module CSE invocation;
5. derived-only storage;
6. idempotency;
7. hash-linked proof and ledger;
8. tamper detection;
9. rollback and reapply;
10. provider-native canary and drift readback.

No trust is transferred from the existing CSE Level 5 workflow to a real legal matter. Each matter remains supervised and must earn any later autonomy separately.
