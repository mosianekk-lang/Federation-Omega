# Formation specification
Objective: prepare unattended keyless private-Ops-to-Google deployment for the existing operator and CFRE runtime without activating OIDC in the quarantined public source repository.
Apply mode requires an already trusted Google machine identity and a separately governed private Ops repository; GitHub OIDC cannot create its own absent provider. Completion requires private-repository identity readback, provider readback, successful token exchange, operator revision readback, live allowlist proof, CFRE bind receipt, private runtime health and rollback evidence.
