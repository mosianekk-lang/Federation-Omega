# Forest-First Ω

Forest-First Ω is the integrated strategic-perception organ of AO-HARMONIC v3.

It does **not** replace the existing Forest-First Justice OS, HORIZON-Ω, Ω-SCIENTIA, EvidenceOps/TruthGrid/JFRIE, Formation, Alpha→Omega, Bubbles, Jarvis, ChatGov, LEX or domain engines. It composes them so that the Federation solves the right problem before optimising the visible task.

## Cognitive cycle

`ROOTS → FOREST → HORIZON → TREES → PATHS → DECISION → OMEGA → READBACK → LEARNING`

- **ROOTS** — identify causal origins, competing hypotheses and falsifiers.
- **FOREST** — model the larger objective, system dynamics, risk signals and merits that survive route changes.
- **HORIZON** — run adaptive multi-horizon simulation through HORIZON-Ω; ten remains a consequential minimum profile floor, not a ceiling.
- **TREES** — inspect exact facts, documents, actors, events, evidence and propositions under source/provenance controls.
- **PATHS** — use Formation, Alpha→Omega, the resource market and AO-CRA to generate and rank objective-preserving routes.
- **DECISION** — prefer the minimum sufficient lawful move with reversibility and option value; consequential authority remains human/ChatGov controlled.
- **OMEGA** — keep the desired end-state, victory condition and stop/pivot triggers explicit.
- **READBACK** — execution is not success until the intended target/state is semantically read back where provider effects are involved.
- **LEARNING** — preserve failures and successes, build regressions, and promote only measured reusable lessons.

## Prime invariants

- ACT ON RISK; ACCUSE ON PROOF.
- SOURCE BEFORE CLAIM.
- ACCESS BEFORE ASK.
- RETRIEVE BEFORE RECONSTRUCT.
- ROUTE FAILURE IS NOT OBJECTIVE FAILURE.
- JURISDICTION BEFORE DRAFTING.
- UNDERSTANDING BEFORE FILING.
- ADVERSARIAL TESTING BEFORE RELEASE.
- CONTINUITY BEFORE CHAT LOSS.
- LEARNING BEFORE REPETITION.
- SYSTEM-FIRST for safe, repeatable operational work; owner-first for lived facts, values, judgment and consequential approval.

## Failure cycle

`DETECT → CONTAIN → CLASSIFY → PRESERVE → REMODEL → REROUTE → BUILD IF NEEDED → TEST → READBACK → LEARN → CONTINUE`

A failed route is internal telemetry while an authorised materially equivalent route remains. Owner interruption is reserved for objective-level exhaustion, owner-only knowledge/judgment, material strategy change or consequential approval.
