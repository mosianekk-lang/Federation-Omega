# Project memory

The incident exposed repeated full-DOM scans, complete-ledger rewrites and 30-second
capture cadence in the existing companion. The selected remedy is a thin-client,
event-sourced and content-addressed fabric. This package is the first shadow-mode
implementation. Source, tests, registration, deployment and behavior remain distinct.

The browser layer now has an additive native-Edge diagnostic adapter contract.
It covers aggregate reload, hydration, lifecycle, reconnect, memory-pressure and
long-task signals while remaining disabled until an authorized execution hook
exists. Route configuration and derived health use disjoint enums to prevent the
earlier regulator ambiguity from entering provider selection.
