## Mission

Turn the SLOS coding-intelligence candidate into a complete provider-neutral engineering runtime without creating a second sovereign brain or executor.

The finalization layer composes existing SLOS/Federation organs and adds only residual coding-runtime capabilities:

1. **RepoGraph** — deterministic repository graph, symbol/import/reference ownership, dependency edges, bounded impact analysis and ranked context selection.
2. **Prepared Workspace Forge** — content-addressed workspace identity, base-revision binding, toolchain/dependency digests, explicit write-set, rollback reference, isolation/readback receipt.
3. **Coding Fleet Planner** — Explorer, Architect, Implementer, Tester, Security, Performance, Verifier and Integrator roles with dependency DAGs; only disjoint mutation domains may fan out.
4. **Verification Supercourt** — risk-scaled syntax/compile/lint/type/unit/integration/property/fuzz/mutation/security/dependency/secret/performance/reproducible-build/rollback/semantic-readback/independent-review gates.
5. **Autonomous Capability Closure** — internal reuse and composition before external mechanism harvest, with provenance/risk/proof gates and residual-gap falsifiers.
6. **Federation Runtime Bridge** — a thin adapter to the existing `alpha_omega_v30.sandbox_fleet` and persistent mission sandbox contracts. It creates no duplicate execution authority.
7. **SLOS Finalization Kernel** — compiles one engineering mission through RepoGraph → Architecture Genome → Workspace Forge → Coding Fleet → Capability Closure → mandatory final proof set.
8. **SLOS Readiness Court** — refuses `SLOS_ENGINEERING_RUNTIME_READY` unless source admission, Leak Guard, Airlock, all runtime organs, rollback, semantic readback and independent assurance are proven across at least two receiver identities.
