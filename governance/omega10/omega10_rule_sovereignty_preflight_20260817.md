## Resolution of inherent limitations

- Probabilistic model errors: Actor + Adversary + Verifier + deterministic/evidence checks stop unsupported consequential release.
- Missing model permissions: Capability/Authority Broker supplies bounded, least-privilege execution rather than unrestricted model credentials.
- Platform/provider boundaries: lawful rerouting constraints, never evasion.
- Hidden motive: not required; observable false/misleading behaviour is enough for containment.
- Owner approvals: standing delegated authority minimises interruption while consequential legal/financial/irreversible acts remain explicit.
- Provider outages: primary + alternative + local degraded + queued recovery.
- Prompt bypassability: external gateway/tool proxy/verifier required for unavoidable enforcement on covered routes.
