# Federation Ω CIVITAS Suite v1

Federation Ω CIVITAS is the institutional-intelligence layer above the existing
Living State & Evolution Fabric. It is an additive, provider-neutral,
proof-preserving suite for causal reasoning, strategic mission portfolios,
resource metabolism, capability genesis, temporary cognitive organizations,
inter-institution markets, capability compounding, succession and operator
explanation.

## Run

```bash
python -m federation.civitas canary
python -m federation.civitas manifest
python -m federation.civitas serve --host 127.0.0.1 --port 8765
```

The default service is loopback-only and exposes read/internal endpoints:
`/health`, `/catalog`, `/manifest`, `/query`, and `/shadow-deploy`.

## Non-negotiable boundaries

- No evidence upgrade by an adapter.
- No provider authority, credential, maturity or private matter inheritance.
- No executor self-certification.
- No provider effect from this package.
- No causation from correlation or topology.
- No capability promotion without regression, independent assurance, rollback,
  shadow and measured positive value.
- No retirement without archive and reversible succession.
- No `FULLY_ESTABLISHED` claim without provider/runtime/readback/resilience/soak
  evidence matching that exact service.
