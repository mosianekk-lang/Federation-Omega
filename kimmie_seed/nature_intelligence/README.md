# Kimmie Seed — Nature Intelligence Child Lane

## Mission

Convert observed mechanisms from authorised nature sources into bounded, testable engineering hypotheses without treating analogy as proof.

## Current release boundary

This package provides a provenance-controlled acquisition runtime, manifest and regression tests. The runtime downloads source text transiently, validates source markers, computes hashes and statistics, records bounded mechanism hypotheses and discards full text.

It does **not** claim that a mechanism is scientifically correct for a target system, that any engineering translation is useful, or that the lane has reached ROOTED or higher maturity.

## Verified-stage contract

- **SEED:** mission, owner and candidate sources exist.
- **GERMINATED:** at least one source is actually fetched by an external workflow, validated, hashed and durably read back with passing tests.
- **ROOTED:** acquisition and translation repeat successfully with persistent monitoring, maintenance and recovery evidence.
- **SPROUT:** one mechanism hypothesis produces a useful tested capability or design improvement with independent proof.
- **SAPLING:** the mechanism translation is reusable across multiple systems or domains with persistent monitoring.
- **MATURE:** sustained operational value and complete ownership are verified.
- **FEDERATED:** independently governed environments reuse the capability with identity and provenance intact.

## Safety rules

1. Do not commit full source texts.
2. Preserve source URL, source ID, title, author, declared rights and retrieval timestamp.
3. Separate observation, interpretation, hypothesis, test and accepted mechanism.
4. Reject a mechanism translation when target conditions differ materially.
5. Do not promote maturity based on documentation or workflow configuration alone.
